# Task 5: Exploratory Data Analysis (EDA) — Titanic Dataset

## Objective
Explore the Titanic dataset using descriptive statistics and visualizations, identify patterns and anomalies, and summarize the findings.

## Files
- `Task5_Titanic_EDA.ipynb` — Jupyter Notebook with analysis and charts.
- `EDA_Findings_Report.pdf` — concise report of methods, observations, and conclusions.
- `requirements.txt` — Python packages required.

## How to run
1. Install Python and Jupyter Notebook (or use free Google Colab).
2. Install packages: `pip install -r requirements.txt`
3. Open `Task5_Titanic_EDA.ipynb` and run cells from top to bottom.
4. The notebook downloads the public Seaborn Titanic CSV on first run. If download is blocked, download `titanic.csv` from the Seaborn-data GitHub repository and put it beside the notebook.
5. Review the charts and output tables, then commit the notebook, PDF report, and README to a new GitHub repository.

## Main findings
The dataset shows differences in survival by sex and passenger class. Age and deck fields have missing values, and fare is right-skewed with high-value outliers. The notebook generates dataset-specific percentages and plots when run.

## Dataset source
Public Seaborn-data Titanic dataset: https://github.com/mwaskom/seaborn-data/blob/master/titanic.csv

## Tools
Python, Pandas, Matplotlib, Seaborn, Jupyter Notebook.
